## PowerCo Customer Churn Analysis
This project focuses on analyzing customer churn data from PowerCo, an energy utility company. The main goal is to identify patterns and reasons for customer attrition and to derive actionable insights to improve customer retention.

# Objective

- Understand customer behavior and the factors leading to churn.
- Identify key attributes affecting churn like contract type, charges, tenure, and services.
- Visualize churn trends across demographics and service features.
- Provide strategic insights for business retention initiatives.

# Dataset Summary
**The dataset contains information about:**

- Demographics (e.g., gender, senior citizen, partner, dependents)
- Account info (tenure, contract type, payment method
- Services used (Internet, Streaming, Tech support)
- Financials (monthly charges, total charges)

# Target Variable: Churn (Yes/No)

- Features of the Analysis
- Data cleaning: Missing value handling, type conversions

# Exploratory Data Analysis (EDA) using:

- Count plots
- Box plots
- Histograms
- Pie charts
- Heatmaps
- Correlation Analysis

# Churn behavior comparison across:

- Contract types
- Monthly charges
- Tenure groups
- Gender and partner status

# Business Insights & Recommendations
**Key Insights**

- Customers with Month-to-Month contracts show the highest churn.
- Higher monthly charges correlate with greater churn likelihood.
- Customers with short tenure (< 1 year) are more likely to leave.
- Online services like Tech Support, Streaming TV are also linked with churn.
